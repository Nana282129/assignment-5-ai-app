# Insight Assistant

## A. What the app does

The Insight Assistant analyzes small structured datasets related to programs, projects, or business performance. The app processes the data and generates AI-powered insights, including risks, trends, and recommendations.

The system uses a small set of local files and produces structured outputs to support decision-making.

## B. Supported tasks

- Generate performance summaries
- Identify trends and patterns
- Highlight risks
- Generate recommendations
- Produce executive summaries
- Explain insights in plain language

## C. Out of scope

- Large datasets
- Real-time analytics
- User authentication
- Production deployment
- Complex dashboards
- External database connections
- General-purpose chatbot functionality
